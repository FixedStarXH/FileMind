# 校园图书借阅分析项目复盘（合成示例）

> 项目、数据和人物均为虚构；本文件没有真实实验结果。

## 目标与数据

目标是观察不同月份和图书类别的借阅变化。输入为合成借阅记录，字段包括借阅日期、归还日期、图书类别和匿名读者编号。原始记录可能有重复行、缺失日期和归还时间早于借阅时间的异常值。

## 实现过程

1. 用 Python 和 pandas 读取数据，保留原始文件摘要与清洗日志。
2. 检查重复编号、日期缺失与时间顺序；把异常记录单独列入复核表。
3. 将可用记录写入 PostgreSQL，通过 SQL JOIN、按月聚合和窗口函数计算趋势。
4. 输出月度趋势图，并在图表旁记录筛选条件、数据版本和查询时间。

## 待补充的可验证证据

- 数据规模、异常记录数和清洗前后差异仍需从真实运行日志取得。
- 查询耗时应在相同硬件与数据量下测量，不能凭印象写“提升 50%”。
