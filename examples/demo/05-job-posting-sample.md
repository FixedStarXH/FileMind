# 数据平台实习生岗位需求（虚构示例）

> 这是为 FileMind 演示编写的虚构岗位，不代表真实招聘信息。

## 工作内容

1. 使用 Python 和 SQL 清洗、核对业务数据，形成可复用的数据处理脚本。
2. 为内部资料检索功能编写 API，并记录接口错误和任务处理状态。
3. 与团队一起检查数据来源、权限边界和查询结果的可追溯性。

## 希望具备

- 熟悉 Python，能够阅读并修改 pandas 数据处理代码。
- 能编写 SQL JOIN、聚合和窗口函数，并解释查询结果。
- 了解 Git、REST API 和 PostgreSQL；有 FastAPI 项目经验更好。
- 能用具体材料证明项目职责和结果，不把未验证的数字写入简历。

## 投递材料清单

- 一页简历，写清项目背景、本人职责和有证据支持的结果。
- 一个可说明数据清洗或 API 开发过程的项目案例。
- 在岗位确实要求时，再附英语或课程证明；没有证明时标注“待补充”。

## 与演示资料的对应关系

示例简历记录了 Python、SQL、Git、PostgreSQL 和 FastAPI 基础；校园图书借阅分析项目复盘记录了数据清洗步骤。证书材料清单中的证明尚未提供。以上仅用于演示资料核对，不构成真实求职建议。
