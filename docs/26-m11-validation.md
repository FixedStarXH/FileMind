# M11 网页注册与多用户验收

## 本次交付

- 登录页提供“注册新账户”，邮箱和至少 12 位密码注册成功后直接进入私人资料库。
- 后端提供 `POST /api/v1/auth/register`，创建独立用户和会话，返回 CSRF token。
- 注册有同源 Origin 校验、Redis 请求限流、邮箱唯一性和可配置账户总数上限。
- `.env` 中可用 `REGISTRATION_ENABLED=false` 暂停注册，`REGISTRATION_MAX_USERS` 调整默认的 20 人上限。管理员命令创建用户仍可使用。

## 2026-11-10 本地验证

| 检查 | 结果 |
|---|---|
| 前端构建、Ruff、mypy | 通过 |
| 错误 Origin 注册 | 403 |
| 两个不同邮箱注册 | 均返回 201，各自 `GET /auth/me` 返回不同用户 ID 和对应邮箱 |
| 重复邮箱注册 | 409 |
| Edge 桌面页面注册 | 注册后自动进入资料库，`GET /auth/me` 为新账户 |
| 临时账户清理 | 已清理验证创建的账户 |

## 部署边界

当前没有邮箱所有权验证、找回密码邮件和平台管理员网页。它适合小规模自托管多人使用；准备面向不受控公众开放前，需要补齐邮件验证、找回密码和更严格的反滥用措施。账户空间彼此隔离，尚不支持多人共同编辑或共享同一资料库。
