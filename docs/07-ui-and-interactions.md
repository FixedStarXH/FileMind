# 07 页面与交互设计

网页工具应用，电脑优先，中文界面。用户已选定 A「清晰资料库」作为视觉方向。M1 已实现登录页和账户设置页；M2 接入资料库工作区、目录和标签、文件列表与详情、版本管理以及回收站；M3 增加任务中心、排队、取消和重试；M4 增加结构化预览与解析阶段状态；M5 加入全文检索；M6 增加独立 AI 问答工作区、范围选择、SSE 进度和来源定位。

使用 ui-ux-pro-max skill 检索设计参考。首次 design-system 返回营销页布局，不适用于文件工作区；随后 product 查询匹配 File Manager & Transfer，采用“文件树 + 简洁平面布局 + 中性色与类型色”。不采用营销页 Hero 和复杂动画。

## 1. 信息架构

| 页面/路由 | 主要内容 | 核心操作 |
|---|---|---|
| /login | 账户登录、错误提示 | 登录；无公开注册入口 |
| /library | 左侧目录/标签，中央文件列表，右侧详情抽屉 | 上传、筛选、选择、收藏、改名、移动 |
| /documents/:id | 预览主体、版本切换、属性、来源问答入口 | 页码定位、下载、上传新版本 |
| /search | 查询输入、模式/范围筛选、命中片段 | 定位原文、对结果提问 |
| /assistant/:conversationId | 对话、范围选择、引用侧栏 | 发送、停止、跳转证据 |
| /runs/:id | 工具步骤摘要、方案差异、审批/结果 | 勾选操作、确认、拒绝、取消 |
| /application-packs | 需求输入、候选材料、缺失清单、导出历史 | 创建任务、确认打包、下载 |

文档详情切换为“目录/页码 + 预览 + 问答/引用”布局。引用点击更新可分享给自己的深链接参数 version/page/locator，不创建公开分享链接。

M4 在文件详情的版本记录中提供预览入口：PDF.js 按页渲染并叠加 OCR 框；图片叠加 OCR 框；DOCX、PPTX、TXT、MD 显示安全转义的结构化文本与原文位置。低置信 OCR 显示提示，解析失败显示可理解原因与“重新解析”。预览框从鉴权 content API 获取原件，支持 Range；解析状态自动刷新。M5 搜索栏支持文件名即时筛选与正文查询，用户可选关键词、语义或混合模式；搜索沿用当前文件夹/标签/收件箱范围，否则明确搜索全部当前文件。结果显示来源位置与片段；向量不可用时提示混合模式已退回关键词。

## 3. 关键交互

- 上传：点击或拖放均可；每批最多20项、浏览器并发3项。每项显示上传进度与后续解析阶段；只重传失败项。页面刷新后服务器任务继续，但未完成的传输需用户重新选择文件，首版不支持断点续传。
- 无文件：说明支持格式与大小，提供上传按钮。演示样例可以由部署者通过普通上传导入专用演示账户，不增加独立“样例导入”接口。
- 重复文件：提示已有文件名称与位置，提供查看；不自动把它当成新版本。
- Agent 范围：聊天输入框上方始终显示选中的文件/文件夹；空范围不可发送；全库检索需显式选择。
- 审批：变更前/后并列，显示理由与证据，支持逐项取消选择；按钮写“应用 6 项修改”而非模糊“确定”。revision 冲突时保留方案供查看，但要求重新生成。
- 引用：显示文件名、页码/段落/幻灯片、历史版本标记。识别质量低的片段显示提示，不用模型口吻掩盖 OCR 错误。
- 删除：回收站可恢复；永久删除弹窗要求输入文件名并解释相关聊天/导出也会清理。
- 无 Key：AI 入口展示“管理员尚未配置模型”，文件管理仍可使用；本地向量缺失时明确仅关键词可用。
- 导出：文件列表的手动导出与 Agent 推荐资料包分开呈现；前者由用户直接选择文件，后者先预览清单和缺失项并确认。显示任务状态、包大小、24小时失效时间；原材料被删除时显示包已失效，禁止下载。

## 4. 必须覆盖的状态

每个列表：加载、空、成功、失败、筛选无结果；每次写操作：提交中、成功、校验错误、版本冲突、权限失效。预览另含无法解析/正在解析/历史版本/源文件不可用。Agent 含排队、检索中、等待确认、确认过期、部分操作未选择、失败、取消、成功。

错误应提供可执行动作：重试、返回列表、重新选择范围或查看原因。页面不展示堆栈、内部工具参数、向量维数等实现信息。

## 5. 视觉与无障碍

建议浅色中性背景、深色正文、蓝绿色主操作，文件类型用图标和文本共同区分；中文采用系统字体，避免运行时依赖国外字体 CDN。基础字号16px、列表可14px，正文行高1.5以上；间距4/8/12/16/24/32。

常规文本对比度≥4.5:1，所有可操作图标有标签、可见键盘焦点；对话框焦点锁定并在关闭后返回触发按钮；上传有键盘入口，触控目标尽量≥44px。状态不只依赖颜色；遵守 prefers-reduced-motion。

≥1280px 三栏，768–1279px 详情抽屉，<768px 单栏文件卡片，目录收进抽屉，预览与问答分页切换。移动端支持上传/查找/阅读/审批，不强行缩小桌面表格。

前端不得在 localStorage 缓存全文、Key 或 Session token；Query 缓存在退出时清除。SSE 断线显示重连状态，最多重试退避到30秒，必要时回退 GET run 轮询。
