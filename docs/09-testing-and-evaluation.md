# 09 验收、测试与 Agent 评测

所有指标为计划目标，只有保存实测报告后才能写入简历为成果。测试围绕跨模块风险与用户路径，避免只验证 mock 返回值。

## 1. 测试层次

| 层 | 验证点 | 工具 |
|---|---|---|
| 单元 | 分段边界、locator、RRF、类型校验、状态转换、预算 | pytest |
| 集成 | 实际 PostgreSQL/pgvector、Redis、文件卷；上传→索引→查询 | pytest + Compose |
| 契约 | OpenAPI 快照、错误模型、幂等响应、事件序号 | pytest + schema 校验 |
| UI | 文件选择、错误反馈、审批勾选、引用组件 | Vitest + Testing Library |
| E2E | 上传→查询→引用→审批→导出→回收/恢复 | Playwright，Edge 主验收 |
| 评测 | 混合检索、事实引用、缺项识别、工具越权防护 | 版本化 JSONL + 人工复核 |

## 2. 必过用例

1. A 用户无法读取 B 的文件、chunk、历史版本、run、SSE、审批、下载与导出。
2. 重复队列消息、并发审批点击、worker 崩溃后重启均不重复应用元数据修改。
3. 上传期间容量耗尽、临时文件写入后事务失败、并发重复上传：额度与文件引用正确，不泄漏孤儿对象。
4. 新版本索引失败后旧版本仍可搜索；重建时无半套片段；取消后旧 worker 不得迟到激活。
5. 计划生成后用户改名、换版本或删文件：审批返回冲突且整批不修改。
6. SSE 在事件持久化后断线，重连不丢事件、不重复展示；超过保留期能恢复快照。
7. 恶意文件名、错误 MIME、压缩炸弹、超页数、损坏/加密 PDF、脚本 Markdown 均被隔离。
8. 文档中含提示注入，Agent 无法读其他用户资料、发送邮件、执行命令或绕过审批。
9. 永久删除后搜索、原下载地址、聊天正文、checkpoint、历史事件、ZIP 都不能恢复被删内容。
10. Key 为空、模型超时、429、非法工具参数、错误引用编号：明确失败/降级，不显示伪成功。
11. 新版本引用旧原文正确定位；DOCX 引用段落不冒充页码；OCR bbox 与校正方向一致。
12. 日常文件管理在无 DeepSeek Key 时可独立运行。

## 3. 评测数据集与指标

首批100份授权/合成材料（含中文课件、简历、证书、英文摘要、扫描图）；200条互不重叠的问题：单文件可回答120、无答案40、多文件组合可回答40。按文件主题划分调参集/保留集，禁止同文件问题同时落入二者导致泄漏。每条可回答问题标注一个或多个足够回答的证据片段，并保留人工标注规范。

| 指标 | 计算 | 首版目标 |
|---|---|---|
| Recall@10 | Top10命中标注证据的问题比例 | ≥85% |
| 引用可定位率 | 可打开正确版本与定位的引用/全部引用 | 100% |
| 引用支持率 | 引用实际支持的事实断言/抽查事实断言 | ≥90%，人工复核 |
| 无答案处理正确率 | 缺证据时说明不足的问题/无答案问题 | ≥90% |
| 整理计划有效率 | 满足Schema、权限、revision与动作约束的方案/方案数 | ≥95% |
| 需要确认的操作绕过数 | 未审批却成功写入的操作数 | 0 |
| 跨用户泄露数 | 越权测试中读到任何他人内容 | 0 |

对照 keyword / semantic / hybrid 三组，固定分段、数据与问题，报告准确率、耗时、token；添加 Agent 相对单次检索的收益与成本，避免只展示最成功的演示。语义质量模型评分只能辅助，最终抽样人工判定。

## 4. 性能与故障演练

热模型搜索测5并发、20k片段；记录P50/P95、CPU/内存、冷启动。OCR 用10/50/200页样本记录吞吐和峰值内存，不在验证前承诺完成时间。SSE 测20连接及断线恢复。worker kill、Redis重启、DB短暂不可用、磁盘满分别验证恢复与错误状态。

发布门槛：关键E2E通过；越权/审批绕过为0；备份恢复演练完成；文档和OpenAPI同步；已知限制写入发布说明。真实DeepSeek评测需配置Key后完成，无Key mock通过不能替代该门槛。

视觉方向的实际原型和电脑/手机截图属于前端开工前的设计确认，不属于功能E2E或真实模型评测。
