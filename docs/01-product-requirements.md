# 01 产品需求（PRD）

版本 v0.1 · 2026-11-08 · 设计基线。

## 1. 产品目标

用户上传散落的学习与求职材料后，能找到原文、得到带证据的回答，并在确认后让 Agent 整理材料。核心演示：上传课件与证书 → 查询某项经历的证明 → 预览整理方案 → 导出求职资料包。

目标用户为大学生及求职者。支持多个独立私人账户，用户可在网页注册；管理员仍可通过命令创建账户。首版使用中文界面，主要检索中文材料，保留英文文件处理能力，英文检索质量独立评测。

## 2. 首版范围与验收

| ID | 功能 | 验收条件 |
|---|---|---|
| F01 | 注册、登录与私人资料库 | 网页注册、登录、退出、改密码；账户之间看不到文件、任务、对话和下载内容 |
| F02 | 批量上传 | 每批最多 20 个、单文件最大 50 MiB；逐文件进度、失败重传、相同内容提示 |
| F03 | 文件管理 | 文件夹、标签、收藏、名称编辑、列表筛选、排序；名称不改变原始文件内容 |
| F04 | 解析与预览 | PDF、DOCX、PPTX、TXT、MD、PNG、JPG/JPEG；显示实际处理阶段与错误原因 |
| F05 | 搜索 | 文件名/标签筛选、关键词全文、语义、混合检索；结果有出处和片段 |
| F06 | 资料问答 | 选择文件范围、多轮追问、引用跳转；没有证据时说明未找到，不伪造来源 |
| F07 | 整理 Agent | 在选定范围内建议分类、改名、标签；预览差异、逐项选择、确认后应用 |
| F08 | 求职资料包 Agent | 输入用途与材料要求，生成有来源的材料清单及缺失项；确认后打包选中的原文件 |
| F09 | 版本与回收站 | 显式上传新版本、浏览历史版本；删除进入回收站，30 天内可恢复 |
| F10 | 任务中心 | 查看解析/Agent/导出进度，取消、重试、查看失败信息；重启后可恢复 |
| F11 | 设置与导出 | AI 云端使用开关、额度展示；单文件下载及资料包 ZIP 导出 |
| F12 | 操作记录 | 显示用户确认、批量变更、导出、删除的时间与结果 |

### 文件支持契约

| 类型 | 提取方式 | 预览与引用定位 |
|---|---|---|
| PDF | pypdf 提取；少于30个可见字符的页面渲染后 OCR | PDF.js；页码，OCR 框可高亮，原生文本按页定位 |
| DOCX | python-docx，段落/表格提取 | 安全渲染的段落视图；段落编号，不承诺 Word 原样排版 |
| PPTX | python-pptx 提取幻灯片文本；本地 LibreOffice 生成整页 PDF | PDF.js 按幻灯片展示完整页面；转换失败时回退到图片与文字近似布局；幻灯片编号，嵌入图片中的文字不识别 |
| TXT/MD | UTF-8，UTF-8 BOM；其他编码提示转换 | 转义文本/清洗后的 Markdown；行号 |
| PNG/JPEG | RapidOCR，校正 EXIF 方向 | 图片与 OCR 框坐标；展示识别质量提示 |

PDF 最多 200 页，需 OCR 的 PDF 页面渲染上限为 2,000 万像素；图片最多 4,000 万像素；DOCX 最多 5,000 段落、PPTX 最多 300 页；超限解析失败并保留下载能力。ZIP、可执行文件、旧版 DOC/PPT、音视频不接收；加密 PDF 不解析，上传时可识别则拒绝，否则记录解析失败并允许原件下载。DOCX/PPTX 解压预算最大 300 MiB、10,000 个条目，限制压缩比 100:1；不执行宏、脚本或外部链接。复杂公式、手写、跨页表格精确还原不是首版承诺。

### 用户故事

1. 临近考试：上传操作系统课件，问“死锁的四个条件在哪几页”，点击引用返回原页。
2. 准备求职：上传简历、证书和项目说明，要求“整理后端实习申请材料”，系统列出依据、缺失证明和打包清单。
3. 日常整理：选定“收件箱”，预览改名/标签/移动建议，取消部分建议后一次确认；失败不出现半批元数据修改。
4. 错误处理：扫描 PDF 识别失败后，用户仍可下载原文件，并可以手动重试解析。

## 3. 版本划分

- R0 可用基础：F01–F04、F09 基础生命周期、单文件下载；无 Key 也能使用。对应开发模块 M0–M4。
- R1 智能检索：F05、F06，本地索引和引用定位。对应 M5–M6；F06 的真实 AI 验收需要 Key。
- R2 首版完整交付：F07–F12，审批、任务恢复、导出、评测和部署。对应 M7–M10，其中 F10 的任务底座在 M3 提前完成。
- 后续候选：桌面目录同步、在线共享、团队权限、Office 原样预览、近似重复文档比较、多语言向量模型、MCP 对外工具服务。未列为首版验收内容。

## 4. 业务规则

- “收件箱”是未归入自建文件夹的视图，即 folder_id=null；“全部文件”包含所有 active 文件。首次上传默认进入收件箱；AI 建议不自动修改用户元数据。普通手动改名/标签不需要 Agent 审批。
- 同用户重复上传与现有 active 文件的**当前版本**完全相同的内容时，不创建新文件，返回已有文件；仅历史版本或回收站中存在相同 blob 时可复用存储并创建新文件。跨用户不暴露重复信息。相同文件名可并存。
- 上传新版本必须指定目标文件；文件列表有当前版本，历史引用绑定实际使用的版本。
- 新版本解析失败不切换当前可搜索版本；文件详情显示“新版本待处理/失败”。首次上传失败则无可搜索版本。
- 首版回收站支持单项恢复和手动永久删除。永久删除后原文及派生数据不可通过历史聊天继续访问。
- 求职资料包只选择已有材料与生成清单，不编造学历、成绩、项目或证书，不向招聘方发送文件。用户手动选择文件直接导出属于明确用户操作；Agent 推荐的资料包必须先展示清单并经用户确认。
- 每账户默认 2 GiB 额度，包括回收站、历史版本和导出产物；超过额度返回明确错误。可以由部署者调整。

## 5. 非功能目标

基准数据：1,000 个文件、约 20,000 个片段；参考测试环境 4 vCPU/8 GiB Linux、CPU 推理、单 OCR 进程，实际结果须记录设备和依赖锁版本。

- 非文件传输的元数据接口 P95 < 500ms；热模型混合搜索 P95 < 2s（5 并发）。这些是目标，未实测。
- 大文件异步处理，不阻塞文件列表；页面显示排队/阶段进度，不显示虚假的模型完成百分比。
- 网络中断可重新连接事件流；取消在阶段检查点生效，已产生的费用不可撤销。
- Edge 当前稳定版验证桌面关键路径；375px 手机宽度无页面级横向溢出。
- 不使用假数据表示真实处理成功；无 Key 时显示 AI 未配置，保留文件管理与可用的本地搜索。
