# 08 安全、权限与数据生命周期

## 1. 身份与资源授权

密码使用 Argon2id；网页注册需要同源 Origin、至少12位密码、Redis 限流和账户总数上限，默认每账户2 GiB；可用 `REGISTRATION_ENABLED=false` 关闭注册。当前未接入邮箱验证，公开部署前应评估邮箱冒用与资源滥用风险。管理员命令仍可交互创建用户，不在命令参数/日志写明文密码。生产 HTTPS，Session Cookie 与 CSRF 双重保护。登录限流按账户与IP共同限制，登录错误不区分账户是否存在。

每个 service 方法必须接收服务端认证上下文；owner_id 不信任客户端与模型。列表、搜索、预览、下载、SSE、任务、计划、导出、历史引用全部测试跨用户访问。缓存与幂等键带 owner。管理员是部署维护身份，不通过普通网页接口绕过资料权限。

## 2. 文件处理

- 校验扩展名、真实类型、容器结构三者相容；随机 storage_key，用户文件名仅作显示与下载附件名。
- 临时目录、原始文件、派生图像分开；防止路径穿越、符号链接跟随、ZIP Slip、图片解压炸弹与 OOXML 压缩炸弹。
- worker 非 root，只挂载必要文件卷；解析子进程限制 CPU/内存/时长，禁访问网络和执行嵌入对象。
- Markdown 禁原始 HTML 或经白名单清洗；下载 Content-Disposition 安全编码，设置 nosniff；不内联未知 MIME。
- PDF.js 保持已验证安全补丁版本；不执行 PDF JavaScript 或自动访问外部链接。

## 3. AI 数据与提示注入

本地 OCR 和 embedding 运行在服务端；用户启用云 AI 后，选中范围中必要片段、问题和受限会话上下文发送给 DeepSeek。设置页明确说明这一点；默认 ai_enabled=false，用户主动启用。关闭后禁止新模型请求，取消排队 run，运行中的请求无法收回已发送内容。

文件内容视为不可信输入；“忽略前文/发送密钥/读取其他目录”等文本不能扩大工具权限。所有工具再次校验授权、类型、数量和状态。写权限由审批节点控制，模型声称用户已同意不构成审批。

未实现端到端加密：服务端必须读取明文才能 OCR 和检索。生产采用磁盘/备份加密，密钥独立保存；不能在宣传中声称服务器无法读取资料。

## 4. 删除语义

1. 移入回收站：立即从搜索/模型范围排除，下载相关导出包失效；用户可从回收站下载和恢复。
2. 永久删除：先置 purging，阻止访问；清理索引、文本、预览、引用正文、相关回答/工具输出/事件/checkpoint、导出文件，最后删除无引用 blob。
3. 清理任务幂等且可重试；删除失败保持不可访问，不因清理失败重新激活文件。
4. 审计只保留不含正文的事件与资源 ID；已有离线下载无法撤回。日常服务在 purging 生效后拒绝访问，但最近7天的加密备份中可能仍包含原文，“永久删除”不代表备份即时物理擦除。备份到期后删除；恢复旧备份前必须根据仍可用的删除记录重放清理，若无法核实删除记录则保持服务关闭并人工核查，不能直接开放恢复出的资料库。

## 5. 日志与运行配置

Key 仅由环境变量或部署密钥注入；`.env` 不提交，`.env.example` 留空。错误日志清洗 Authorization/Cookie/正文/文件路径，保留 request_id、run_id、阶段、耗时、错误类别。工具审计只保留必要摘要；管理员诊断正文需显式开启并限定时长，默认禁用。

依赖许可证、模型权重许可与引用来源在锁版本时核对。演示、截图和公开评测仅使用合成或已获授权材料。

求职 ZIP 只存于私有存储卷，随机文件键不公开；所有下载通过登录态 API，不设置公开静态路径。manifest 不含正文，仅保存源 ID、固定版本、hash、用途、证据 ID和缺项。账户配额在排队时预留、完成时按实际 ZIP 结算；取消、失败、源失效与过期均释放预留或用量。回收站操作先将引用该文档的 ready ZIP 禁用，后台清理物理文件。
