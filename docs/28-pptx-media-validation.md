# M13 PPTX 图片预览验收

## 本次交付

- PPTX 按页展示嵌入的位图和文本框，使用原件中记录的位置构建近似幻灯片画布。
- 图片经服务端校验、缩小并转换为 PNG，通过持有者认证的独立接口读取；页面可点击图片单独查看。
- 单页最多展示 120 个元素；过大或不支持的图片会提示下载原件。

## 已知边界

这不是 PowerPoint 原样渲染。母版、动画、复杂图表、分组中的图片和精确字体样式不保证还原；嵌入图片不做 OCR。DOCX 仍以段落和表格文字为主，嵌入图片尚未加入在线预览。
