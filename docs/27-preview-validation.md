# M12 多格式文档预览验收

## 实现范围

- PDF：原页渲染、翻页、缩放及当前页提取文字；图片：原图及 OCR 文字。
- DOCX：段落和表格单元格文字；PPTX：按幻灯片切换提取文字；TXT/MD：按原始行号阅读。
- 所有提取文字按每次 200 条加载，长文件可继续加载；弹层支持 Escape 关闭、焦点留在弹层内。
- 下载原件入口保留。Office 文件为安全转义的文本视图，不还原原始版式或嵌入图片。

上述六种测试文件是本地合成样本，已导入演示账号的“格式预览样本”文件夹；样本二进制文件及账号密码不提交到 Git。现有六份 Markdown 演示资料仍可预览。

## 已知边界

DOCX/PPTX 的图片、图表与精确排版仍需下载原件查看。Excel、旧版 DOC/PPT、音视频和 ZIP 不属于当前上传支持范围。OCR 质量依赖原图清晰度；识别文字应与原图核对。
