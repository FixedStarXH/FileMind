# FileMind 使用流程手册

FileMind 是可供多人使用的学习与求职资料库，每个账户都有独立的私人空间。当前项目的 DeepSeek Key 留空，因此文件管理、预览、关键词检索和手动导出可用，AI 问答、智能整理和智能资料包暂不可用。

## 1. 打开应用

如果管理员已经启动服务，直接在 Edge 打开他提供的 FileMind 地址并登录。本地开发地址是 <http://127.0.0.1:5173/>。打开失败时，在项目根目录检查 API，再启动前端：

```powershell
docker compose up -d --build
curl.exe http://127.0.0.1:8000/health/ready
cd frontend
npm ci
npm run dev
```

`npm ci` 首次安装或锁文件变化后执行即可。`/health/ready` 返回 `status: ready` 表示数据库、队列和文件存储可用；`deepseek: not_configured` 不影响基础资料库。首次部署应先按 [README](../README.md) 从 `.env.example` 建立本地 `.env`，填写数据库密码和 Session Secret。生产地址由部署者提供，需使用 HTTPS。

没有账户时，打开页面选择 **注册新账户**，输入邮箱、至少12位密码并再次确认；注册成功后直接进入资料库。管理员也可在项目根目录执行以下命令创建账户：

```powershell
docker compose exec api /app/.venv/bin/filemind create-user your-email@example.com
```

以后在登录页输入邮箱和密码，点击 **登录资料库**。

## 2. 十分钟走通基础流程

1. **上传资料**：进入 **全部文件**，点击 **上传文件**，选择 `examples/demo/` 里的六份合成 Markdown 文件；也可以拖到资料库。每次最多 20 个文件，单个不超过 50 MiB。
2. **等待处理**：上传队列显示传输结果；文件状态从“排队中”等阶段变为 **已解析并可检索**。点左侧 **任务中心** 可查看后台进度；解析失败时在文件详情点 **重新解析**，或在任务中心重试失败任务。
3. **查找内容**：返回 **全部文件**，在顶部 **搜索文件名或正文…** 输入“图神经网络”，将 **检索方式** 选为 **关键词**，按 Enter。输入时的列表先筛文件名；按 Enter 后展示正文匹配结果。点击结果打开文件详情。
4. **预览和下载**：在文件详情的 **版本记录** 点眼睛图标预览；点下载图标或底部 **下载原件** 保存原文件。
5. **整理资料**：在左侧 **文件夹** 或 **标签** 旁点击加号建立分类。选中文件后修改标题、所在文件夹或标签，点击 **保存资料信息**。可在文件列表点星标收藏。
6. **手动打包**：左侧进入 **求职资料包** → **手动导出**，勾选已完成识别的文件，点击 **创建手动导出**。在 **导出记录** 等待“资料包已就绪”，再点 **下载** 获取 ZIP。手动导出不需要 DeepSeek Key。
7. **试用回收站**：返回资料库，选中文件并点 **移入回收站**；左侧 **回收站** 可用 **恢复文件** 找回。源文件进入回收站后，包含它的旧 ZIP 会失效，需重新导出。
8. **退出**：点页面右上角的退出图标。账户设置中可查看存储用量或修改密码；改密后需重新登录。

演示资料全为虚构内容，不对应真实个人、证书或论文结果。

## 3. 日常功能速查

| 目标 | 页面路径与操作 | 注意事项 |
|---|---|---|
| 添加文件 | 资料库 → **上传文件**，或拖放到页面 | 支持 PDF、DOCX、PPTX、TXT、MD、PNG、JPG/JPEG；每批最多 20 个，单个最多 50 MiB。相同内容会提示重复。 |
| 上传新版本 | 点击文件 → **版本记录** → **新版本** | 在版本记录中分别预览、下载各版本；解析新版本期间旧的可检索版本仍保留。 |
| 搜索 | 资料库顶部搜索框 → 选择 **混合/关键词/语义** → Enter | 当前收件箱、文件夹或标签会限定正文检索范围；要查全库先点 **全部文件**。向量模型不可用时选择 **关键词**。 |
| 管理分类 | 左侧文件夹/标签旁加号；文件详情编辑位置与标签后保存 | 删除标签不会删除文件；只能删除空文件夹。 |
| 查看后台处理 | 左侧 **任务中心** | 解析任务可取消；失败或已取消的任务可重试。 |
| 恢复或彻底删除 | 左侧 **回收站** → 选择文件 | 回收站保留 30 天。**永久删除**需要输入文件名确认，删除后无法恢复。 |
| 导出原文件 | 文件详情 → **下载原件** | 下载需保持登录；他人的文件不可访问。 |

## 4. AI 功能启用后的操作

以下功能需要管理员配置 DeepSeek Key，然后在 **账户设置** 打开 **启用 AI 资料问答**。启用后，所选资料的相关文本片段会发送到 DeepSeek；OCR 和向量检索在本地执行。Key 仍为空时页面会显示“管理员尚未配置 DeepSeek API Key”，无需反复点击 AI 按钮。

### AI 问答

1. 左侧点 **AI 问答**，选择 **资料范围**：全部资料、收件箱、某个文件夹或标签。全库范围需要明确选择。
2. 输入问题并发送。回答会逐步显示，完成后可查看来源卡片中的文件名、位置和摘录；没有足够资料时应说明无法回答。
3. 左侧可查看已有对话或点 **新建对话**。正在生成时可点 **停止**。

当前引用卡片显示来源和位置，但还不能从卡片直接点击跳转原文。需要核对时，请回到资料库打开对应文件版本预览。

### 资料整理

1. 左侧点 **资料整理**，选择收件箱、文件夹或标签作为范围，填写整理要求，点 **生成整理方案**。
2. 对照每项的“当前”和“建议”以及理由；取消勾选不想应用的项目。
3. 点 **确认应用 N 项** 才会修改标题、文件夹或标签；也可以点 **拒绝方案**。方案 24 小时内有效。原文件内容不会被改写。

### 智能求职资料包

1. 左侧点 **求职资料包** → **智能资料包**，选资料范围，输入目标岗位与材料要求，点 **分析资料**。
2. 查看推荐材料的用途、来源摘录和“还需要补充的材料”。逐份勾选要导出的文件。
3. 点 **确认并生成 ZIP**；在 **导出记录** 等待就绪后下载。系统只会打包已经上传且完成识别的文件，不会替你补造证书或经历，也不会代发给招聘方。

无论智能还是手动导出，ZIP 都会计入存储用量，通常在生成后 24 小时到期；源文件移入回收站后会提前失效。

## 5. 常见问题

| 现象 | 处理方式 |
|---|---|
| 5173 地址打不开 | 确认 `frontend` 目录中的 `npm run dev` 仍在运行；再检查 `http://127.0.0.1:8000/health/ready`。 |
| 登录提示邮箱或密码错误 | 核对注册邮箱；连续失败过多需等待限流结束。没有账户时点 **注册新账户**。 |
| 文件一直排队或解析失败 | 到 **任务中心** 查看任务状态；失败可重试，原件仍可从文件详情下载。 |
| 搜不到正文 | 等文件变为 **已解析并可检索**；检查当前资料范围，再尝试 **关键词** 模式。 |
| 手动导出没有可选文件 | 先上传文件，等待识别完成；回收站文件不参与导出。 |
| AI 按钮不可用 | 管理员尚未配置 DeepSeek Key，或当前账户未在设置中启用 AI。基础文件管理仍可用。 |
| ZIP 显示过期或失效 | 到 **求职资料包** 重新创建导出；恢复源文件不会重新启用旧 ZIP。 |

需要服务部署、加密备份和恢复步骤时，参见 [部署与运维](10-deployment-and-operations.md)。
